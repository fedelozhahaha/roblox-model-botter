# Roblox Model Helper (Safe)

Herramienta CLI para:

- Buscar modelos públicos por palabra clave.
- Subir un archivo local `.rbxm`/`.rbxmx` a tu propia cuenta.

> Esta herramienta **no** incluye inyección de scripts, spam ni bypass de moderación.

## Uso

```bash
npm install
npm start
```

El programa pedirá tu cookie `.ROBLOSECURITY` para autenticar tu sesión con `noblox.js`.

## Nota de seguridad

No compartas tu cookie con nadie.
